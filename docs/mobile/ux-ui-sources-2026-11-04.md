# Mobilný redesign: overené zdroje a rozhodnutia

Dátum čítania: **4. 11. 2026**. Rozsah: iPhone a Android klient Expo SDK 57 / React Native 0.86 / React 19.2.3 a jeho webový náhľad. Tento dokument je výskumný podklad; sám nepotvrdzuje, že aplikácia spĺňa všetky odporúčania alebo že prešla skúškou na zariadení.

Preštudovaných bolo **33 odlišných primárnych zdrojov** uvedených nižšie: 18 tém Apple HIG, 2 referencie Expo 57, 6 referencií React Native 0.86, 6 vysvetlení kritérií WCAG 2.2 a aktuálne Vercel Web Interface Guidelines. Čítané boli príslušné odporúčania/API, nie iba titulky výsledkov vyhľadávania. Apple HIG HTML pri priamom otvorení vracalo JavaScript obálku; obsah sa načítal z oficiálnej Markdown verzie príslušnej stránky (`.md`). Expo Markdown pri priamom stiahnutí vracalo 403; použité boli dostupné plné oficiálne HTML/indexované stránky. Žiadne sekundárne články alebo sociálne siete nie sú dôkazom v tomto návrhu.

Použité metodiky: inštalované skills **design**, **vercel-react-native-skills** a aktuálne pravidlá **web-design-guidelines**. Vercel odporúčania pre web sa prenášajú do natívneho klienta len tam, kde majú ekvivalent; HTML atribúty sa nekopírujú mechanicky do React Native. Tento výskum nevyžaduje novú knižnicu.

## Čo z toho vyplýva pre aplikáciu

**Liquid Glass je vrstva navigácie a ovládania.** Biele nepriehľadné skupiny prípadov, úloh a formulárov zostávajú čitateľným obsahom. Sklo má význam v spodnej lište a vybraných plávajúcich ovládačoch. Pre prevádzkovú aplikáciu s textom je vhodný variant `regular`; `clear` je určený najmä nad fotografiami a videom. Sklo sa nemá pridávať na každú kartu. [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials)

**Vizuálna modernizácia musí zlepšiť čitateľnosť.** Apple pre iOS uvádza predvolenú veľkosť textu 17 pt a minimum 11 pt; zároveň odporúča zachovať hierarchiu, obmedziť orezávanie a pri veľkom písme preskladať riadky do stĺpca. Údaje potrebné na prácu preto majú prednosť pred hustotou. Obmedzená veľkosť navigačných popisov môže byť samostatné odôvodnené rozhodnutie, nie globálne obmedzenie všetkého textu. [Apple Typography](https://developer.apple.com/design/human-interface-guidelines/typography)

**Stabilná navigácia a malé množstvo výrazných akcií znižujú nároky na orientáciu.** Zachovanie známej lišty Prehľad · vlastné moduly · Moduly je produktové rozhodnutie v súlade s možnosťou personalizácie. Výskum neukladá zmeniť navigačnú architektúru ani prepnúť všetky ikony na SF Symbols. Konzistentná rodina ikon, viditeľné názvy a jednoznačný výber sú dôležitejšie než dekorácia. [Apple Tab bars](https://developer.apple.com/design/human-interface-guidelines/tab-bars), [Apple SF Symbols](https://developer.apple.com/design/human-interface-guidelines/sf-symbols)

## Priority pre implementáciu

1. **Čitateľnosť a dostupnosť:** zmerať kontrast, zosúladiť tokeny, opraviť text menší než 11 pt, odstrániť nechcené orezanie kľúčových údajov. Preskladať riadky/formuláre pre úzky displej a väčšie písmo. Overiť reálne dotykové oblasti vrátane malých ikonových akcií. Zdroje 3–5, 7, 21–24, 27–30.
2. **Orientácia a poradie práce:** na Prehľade aktívny hovor a naliehavé položky pred sekundárnymi súhrnmi; krátke presné názvy sekcií; zachovať personalizovanú navigáciu a rozpracovaný obsah. Toto poradie je produktový úsudok pre dispečing, podopretý všeobecnými pravidlami hierarchie. Zdroje 2, 5, 15–18.
3. **Spoločné komponenty:** rovnaké nadpisy, skupiny riadkov, stavové štítky, tlačidlá, formulárové polia a prázdne/chybové stavy vo všetkých moduloch. Zdroje 3, 7, 12–14, 17.
4. **Responzívna kostra:** úzka hlavička bez kolízií, dock so zachovanými názvami, dostatok spodného odsadenia pre hovor a safe area; obsah pri väčšej šírke nerozťahovať na nečitateľne dlhé riadky. Zdroje 2, 5, 16, 23, 26, 32.
5. **Materiál a dynamika:** pravidelné natívne sklo len v kostre, ostrá typografia, diskrétna odozva stlačenia a účelný pohyb; fallback a zmeny systémových nastavení sú súčasť návrhu. Zdroje 1, 6, 10–11, 19–22.
6. **Overenie:** 320/390/430 px a väčšia plocha; dlhé slovenské mená, adresy, stavy; 200 % písmo; klávesnica; no-data/offline/error/loading; focus a screen reader; iPhone sklo so zníženou priehľadnosťou/pohybom; Android návrat. Zdroje 3–5, 21–32.

## Verzie, hranice a neistoty

- Apple HIG je priebežne aktualizovaná dokumentácia; ide o znenie načítané v uvedený deň. Platformové sekcie macOS/watchOS/visionOS sa automaticky nevzťahujú na iPhone. Napríklad pravidlá menu capitalization v angličtine neurčujú slovenský pravopis.
- React Native predvolené online stránky už ukazujú 0.88. Výskum API vyššie používa explicitne **0.86**, aby nevznikla neodôvodnená požiadavka na upgrade.
- Expo **SDK 57** referencia pri čítaní uvádzala GlassEffect aj BlurView `~57.0.3`; repozitár používa GlassEffect `~57.0.4`. Dokumentácia preto dokladá API rodiny SDK, nie každú zmenu patch verzie. Pred použitím nového API musí implementátor overiť inštalované typy. Tento výskum neodporúča meniť závislosti.
- Dostupnosť `GlassView` nepotvrdzuje správne vykreslenie v konkrétnej binárke. Expo Go, browser, stará vlastná binárka a aktuálny natívny build majú odlišné možnosti.
- WCAG je webový štandard. Je vhodným merateľným východiskom pre kontrast a webový náhľad; sám nenahrádza natívne VoiceOver/TalkBack a fyzické skúšky. W3C Understanding sú vysvetlenia kritérií, nie samostatná normatívna špecifikácia.
- HIG sú odporúčania pre návrh; splnenie tohto zoznamu nie je záruka App Store schválenia. Výskum sa netýka právnej ani publikačnej spôsobilosti.
- V tejto výskumnej vetve sa neuskutočnil používateľský test s dispečerom ani meranie času úloh. Priority sú dôvodný návrh; konkrétne UX chyby musí dokázať audit aplikácie a overenie implementácie.
