# Prehliadka UI/UX mobilnej appky (28. 10. 2026)

Kontrola terénnej časti appky po doplnení Mojej práce a Pobočky, podľa
[mobilného štandardu](design-standard.md). Appka bežala v prehliadači
(`npx expo start --web`, Chrome) na 390 × 844, 430 × 932 a 320 × 568 bodoch proti
TEST `https://test.dispecing.linkapomoci.sk` so syntetickými účtami: pristavovač
Žilina, miestny dispečer Žilina a syntetický centrálny dispečer s vlastnou
odťahovou zákazkou (`prepare-smoke.mjs`). Údaje (štyri požiadavky pobočky, dve
jazdy, jedna odťahová zákazka) vznikli cez webové API, nikoho nekontaktovali
a na konci sú zrušené; syntetické účty upratal `cleanup-smoke.mjs`.

Server TEST neposiela CORS hlavičky (natívna appka ich nepotrebuje), preto
prehliadačová skúška preposiela volania TEST API cez Playwright a hlavičky
doplní lokálne; server sa nemenil. Snímky sú v
`.context/mobile-ux/` (mimo repozitára): `…-390.png` pred opravou, `…-390-after.png`
po oprave, `…-320.png` a `…-430.png` malé a veľké telefóny.

Prehliadač neukáže všetko: `Alert` (výber fotky, potvrdenie Dokončiť, Zahodiť) je
v react-native-web prázdny, notifikácie a poloha na pozadí sú iba v natívnej
appke. Tieto časti sú skontrolované v kóde a testami, nie ťukaním.

## Čo sedí so štandardom

Horná lišta so Späť a názvom cieľa, spodná lišta s ikonou aj textom, jedna žltá
hlavná akcia na obrazovke, stav vždy farbou aj textom (štítky Pridelené,
Prijaté, Čaká na prevzatie, Prevzaté), ťukacie plochy ≥ 44 b (čipy a segment
majú rozšírenú plochu cez `hitSlop`), formuláre so sekciami a chybou pri tlačidle,
dlhé slovenské texty sa v riadkoch zalomia a v detaile sú celé. Na 320 b sa nič
podstatné neprekrýva okrem bodu D.
